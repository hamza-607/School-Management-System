# School Management System

A Laravel-based backend system designed to manage school operations, including students, teachers, classes, attendance, and roles/permissions.

## Status
This project is currently under active development.  
The backend architecture is the main focus at this stage.

## Frontend / Dashboard
The current dashboard and views are temporary prototypes created using a Vuesax-based template, with additional assistance from AI tools to speed up development and testing.  
The frontend is not a priority at this stage and will be improved later when backend development is complete.

## Features (Backend)
- Authentication & Authorization (Roles / Permissions)
- Students & Teachers Management
- Classes & Subjects
- Attendance System
- Admin Dashboard (Prototype)
- RESTful Controllers & Services

## Tech Stack
- Laravel 11
- MySQL
- Blade (Prototype views)
- Bootstrap (temporary)
